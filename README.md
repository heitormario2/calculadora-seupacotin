# Aplicativo Calculadora SeuPacotin

Calculadora de cotação baseada na tabela fornecida.

## Regra de faixa

- Preto: faixas de 1, 10 e 30 milheiros.
- Branco e Colorido: faixas de 1, 5 e 20 milheiros.
- Promoção: usa automaticamente o valor da última coluna de cada catálogo.
- Nota Fiscal: acrescenta 8% aos valores quando ativada.

## Abrir no computador

Abra o arquivo `index.html` no navegador.

## Instalar no celular

Para instalar como aplicativo, os arquivos precisam estar publicados em um endereço HTTPS.

### Android (Chrome)

1. Abra o endereço publicado no Chrome.
2. Toque em **Instalar aplicativo** quando o aviso aparecer.
3. Se o aviso não aparecer, abra o menu do Chrome e toque em **Adicionar à tela inicial**.

### iPhone (Safari)

1. Abra o endereço publicado no Safari.
2. Toque em **Compartilhar**.
3. Toque em **Adicionar à Tela de Início**.

Depois da primeira abertura, a calculadora funciona mesmo sem internet.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie todos os arquivos e pastas deste pacote.
3. Abra `Settings` > `Pages`.
4. Em `Build and deployment`, selecione `Deploy from a branch`.
5. Escolha a branch `main`, pasta `/root`, e clique em `Save`.
